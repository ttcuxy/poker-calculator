# Poker Calculator

Простой покерный калькулятор (Pot Odds и SPR), написанный на HTML, CSS и JavaScript.

## Использование
Откройте `index.html` в браузере или загрузите проект на GitHub Pages для публикации.

## Компоненты
- `index.html` — основная страница
- `style.css` — стили
- `script.js` — логика калькулятора
